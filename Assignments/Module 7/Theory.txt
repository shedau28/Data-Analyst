8.What is the purpose continuing statement in python?
Ans. The purpose of the continue statement in Python is to skip the remaining code inside the current loop iteration and jump immediately to the next cycle. Unlike the break statement, which stops the entire loop, continue keeps the loop running while selectively bypassing specific elements.


17.  What are negative indexes and why are they used?
Ans. Negative indexes allow you to access elements in a sequence (like arrays, lists, or strings) counting backward from the end rather than the start. Instead of calculating the length of a sequence first, they provide direct, shorthand access to the items at the end (e.g., the last element is -1).


25. What is List? How will you reverse a list?
Ans. A list is a versatile, ordered collection of items that can store multiple elements (like numbers, strings, or other lists) in a single variable. Lists are mutable, meaning you can change, add, or remove elements after they are created.

Reverse Uisng Slicing

print(reversed_list)

Using Reverse method
my_list = [1, 2, 3, 4, 5]
my_list.reverse()
print(my_list)

51.  How Do You Traverse Through a Dictionary Object in Python?
Ans. You can traverse through a dictionary object in Python most efficiently by using a for loop combined with built-in dictionary methods like items(), keys(), or values().

data = {"username": "johndoe", "role": "admin", "status": "active"}

for key, value in data.items():
    print(f"{key}: {value}")
